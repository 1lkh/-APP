# 动作研究与内容规范

## 1. 这次校正解决什么问题

原始动作数据的 `target` 只表达数据集中的一个目标标签，不能直接当作完整训练处方。一个复合动作通常同时包含多个关节动作、多个肌群和不同的训练适应；“参与发力”“主要刺激”“训练目标”必须分开写。

例如：高翻（power clean）的股四头肌会参与第二拉和接杠，但它的核心训练目标是快速产生力量和功率，技术重点是髋、膝、踝三伸展、杠铃近身轨迹和稳定接杠。把它直接写成“练股四”会让用户选择错误的动作和负重。

## 2. 统一字段

每个动作的人工增强数据使用以下字段：

| 字段 | 含义 |
|---|---|
| `primary_goal` | 主要训练适应：力量、肌肥大、爆发力/功率、体能、稳定性或活动度 |
| `movement_pattern` | 关节和动作模式，例如髋铰链、膝主导深蹲、水平推、垂直拉 |
| `primary_muscles` | 对完成动作和主要适应最重要的肌群，不追求穷举 |
| `secondary_muscles` | 协同或等长稳定肌群 |
| `not_the_goal` | 容易误导用户的说法，必要时明确排除 |
| `steps` | 起始、主要阶段、结束/回放的可执行步骤 |
| `cues` | 训练时可以短句提示的动作要点 |
| `common_errors` | 常见代偿和技术错误，不使用“疼痛就是有效”之类表述 |
| `breathing` | 呼吸与躯干压力的简单提示，不替代个体化指导 |
| `programming` | 仅给一般性范围，明确按技术、速度和恢复调整 |
| `safety` | 风险边界、退阶和停止信号 |
| `evidence_level` | A：指南/教材/运动项目技术文献；B：同行评议研究；C：教练资料或待复核 |
| `review_status` | 是否已经过人工校对；未校对动作必须显示待复核 |

开源 CSV 继续保存原始元数据；人工增强层单独放在 `动作增强数据.json`，避免覆盖来源数据，也方便逐条审阅和回滚。

## 3. 已校正的高优先级动作

| 动作 | 原标签的问题 | 当前口径 |
|---|---|---|
| 高翻 | `hamstrings` 不能代表动作目标 | 爆发力/功率；臀、股四、腘绳肌、斜方肌共同参与 |
| 杠铃高翻推举 | `quads` 过于狭窄 | 高翻功率 + 过头推举的全身协调和体能 |
| 农夫行走 | `quads` 把携行动作误写成腿部孤立训练 | 握力、躯干抗侧屈稳定、负重行走能力 |
| 壶铃摆荡 | 不是肩部前平举 | 髋部爆发力/功率；手臂只连接负重 |
| 深蹲跳、跳箱 | 不能只写臀或小腿 | 下肢快速力量、跳跃功率和落地控制 |
| 杠铃硬拉 | 单一 `glutes` 不完整 | 髋伸力量与后侧链，重点是臀、腘绳肌、竖脊肌和握力 |
| 罗马尼亚硬拉 | 单一臀部标签不完整 | 腘绳肌/臀的髋铰链与离心控制 |
| 挺举深蹲 | 单一三角肌标签不完整 | 下肢驱动到推举的全身功率与体能 |
| 单臂杠铃抓举 | 单一三角肌标签不完整 | 单侧爆发力、功率、协调和抗旋转 |

## 4. 证据和写作边界

1. 运动目标优先按动作模式和训练变量定义，不能从一张 GIF 反推“最有效肌肉”。
2. 肌肥大建议使用“在合适负重、接近但不必力竭、渐进超负荷下可能促进”这种表述，不承诺局部塑形或固定结果。
3. 爆发力动作以速度和功率为约束；速度显著下降、接杠不稳或躯干失控时停止该组，不追求力竭。
4. 技术动作的步骤必须覆盖：起始位、负重路径、主要发力阶段、结束位/回放、呼吸和停止信号。
5. 任何疼痛、麻木、眩晕或放射症状都不能被包装成正常训练感觉；页面必须给出退阶或咨询专业人士的提示。
6. 组数、次数和休息仅作一般训练范围，不能替代医生、物理治疗师或持证教练对个体情况的评估。

## 6. 后续审核顺序

第一批已人工复核：高翻、杠铃高翻推举、杠铃深蹲、前蹲、杠铃硬拉、罗马尼亚硬拉、壶铃摆荡、挺举深蹲、农夫行走、单臂杠铃抓举。

下一批按风险和使用频率审核：抓举衍生动作、双力臂、悬垂抬腿、健腹轮、跳箱、深蹲跳、杠铃卧推、肩上推举、引体向上、颈部和拉伸动作。未录入增强层的动作在产品中显示“基础资料，动作要点待教练复核”，不能使用与已复核动作相同的详细处方。

> 这份文件不是医疗建议。高负重举重、爆发力训练、颈部动作和存在伤病史的人群，应在专业人员指导下进行。
