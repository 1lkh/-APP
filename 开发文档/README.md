# 健身 APP 开发文档

这个目录是健身 APP 的独立开发文档 Git 仓库，用于记录需求、架构、市场调研、开发前置决策和版本变更。

## 当前文档

- `健身APP需求文档.md`：完整产品需求文档（PRD）
- `开发概要.md`：开发方向和 MVP 速览
- `市场调研-架构与设计.md`：竞品、架构和设计调研
- `开发前冻结清单.md`：正式开发前的决策、数据、素材、设计和技术验收清单
- `动作研究与内容规范.md`：训练目标、动作模式、证据等级和内容审核规范
- `动作增强数据.json`：人工校正的动作目标、步骤、提示、错误、呼吸和安全边界
- `android/`：Android WebView 工程和可重复构建脚本
- `index.html`、`app.js`、`styles.css`：当前 V1 静态 MVP
- `精选100动作.csv`：MVP 当前使用的精选动作数据

## Git 使用建议

```bash
# 查看版本
git log --oneline

# 保存一次文档变更
git add .
git commit -m "docs: 更新开发文档"

# 回到某个历史版本（先用 git log 找到 commit）
git checkout <commit>
```

当前仓库只管理 `开发文档` 目录内的文件，不管理上级目录的前端代码和素材文件。

## 本地预览

在本目录启动静态服务器：

```bash
python3 -m http.server 4174
```

然后打开 `http://127.0.0.1:4174`。代码通过相对路径读取 `精选100动作.csv`，不能直接双击 HTML 文件运行。
